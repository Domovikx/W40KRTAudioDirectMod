# A/B демки: борьба с акцентом (2026-08-29)

## ПОБЕДИТЕЛЬ (выбор пользователя)

**`t1.2 c0.9 p0.5k10 r0.15`** — оба файла в этой папке:
`t1.2c0.9p0.5k10r0.15_{958665ee,031209d1}.wav`

Полный конфиг: cross_lingual + RL + seed 42 + `--tail-trim` (усиленный:
−40дБ + fade 60мс + отсечение изолированных хвостовых всплесков) + `--s16`.

## Что означает `p0.5 k10 r0.15`

| Ключ | Параметр | Значение | Что делает |
|---|---|---|---|
| `t1.2` | flow-temp | 1.2 | масштаб шума flow-диффузии (сток кода 1.0). 1.2 — чуть живее стока, без ухода в акцент |
| `c0.9` | inference_cfg_rate | 0.9 | сила CFG: насколько выход прижимается к рефу/тексту (сток 0.7) — стабилизирует тембр и произношение |
| `p0.5` | RAS top_p | 0.5 | nucleus-порог LLM-каскада: кандидаты-токены берутся, пока сумма их вероятностей < 0.5 — узкий, детерминированный выбор |
| `k10` | RAS top_k | 10 | потолок кандидатов: не более 10 токенов (сток 25) |
| `r0.15` | RAS tau_r | 0.15 | **анти-повторы**: если токен встретился ≥ `win_size × tau_r` = 10×0.15 = **2 раза** в окне из 10 последних токенов — он банится, и токен выбирается из полного распределения (сток 0.1 → порог 1) |

Итого: живая просодия (t1.2) + жёсткий контроль контекста (c0.9) +
узкий сэмплинг (p0.5/k10) + чуть агрессивнее анти-повторы (r0.15) —
стабильное произношение без акцента, без «заиканий», без хвостовых артефактов.

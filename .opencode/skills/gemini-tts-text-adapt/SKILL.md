# TTS Text Adaptation — Подготовка текста для Gemini TTS

Справочник для саб-агента. Задача: взять `text` из `catalog/people/*.yaml`,
адаптировать под Gemini TTS, записать результат в `gemini_text`.

---

## 1. Gemini TTS — что умеет с текстом

### Audio tags (inline, квадратные скобки)

Ставятся в любом месте текста, управляют доставкой конкретной фразы.
Для русского текста теги всё равно писать **по-английски**.

- `[whispers]` — Шёпот
- `[shouting]` — Крик
- `[laughs]` — Смех
- `[sighs]` — Вздох
- `[gasp]` — Восхищённый вдох
- `[crying]` — Плач
- `[giggles]` — Хихиканье
- `[trembling]` — Дрожащий голос
- `[amazed]` — Удивление
- `[curious]` — Любопытство
- `[excited]` — Возбуждение
- `[mischievously]` — Озорство
- `[panicked]` — Паника
- `[sarcastic]` — Сарказм
- `[serious]` — Серьёзность
- `[tired]` — Усталость
- `[amused]` — Забавно, с усмешкой
- `[chuckles]` — Посмеивается
- `[sly]` — Хитро, вкрадчиво
- `[firm]` — Твёрдо
- `[warmly]` — Тепло
- `[gently]` — Нежно
- `[cheerfully]` — Бодро
- `[determination]` — Решительно
- `[frustration]` — С раздражением
- `[nervousness]` — Нервно
- `[neutral]` — Нейтрально
- `[very fast]` — Очень быстро
- `[slow]` — Медленно
- `[short pause]` — Короткая пауза
- `[long pause]` — Длинная пауза

Два-три тега на фразу — максимум. Не ставить два тега подряд без текста
между ними.

### Промпт-структура (для справки — агент соберёт сам)

```
# AUDIO PROFILE: {speaker_name}
## "{speaker_personality}"

## SCENE: {контекст сцены}

### PERFORMANCE
Style: {стиль}
Pace: {темп}

#### TRANSCRIPT
{gemini_text}
```

> `speaker_name` — это имя из `speaker` (или `name`, если `speaker: null`).
> `speaker_personality` — personality спикера (из его YAML), а не владельца файла.

> **Внимание:** саб-агент не собирает полный промпт. Он только подготавливает
> `gemini_text` — текст, который потом вставится в `#### TRANSCRIPT`.

---

## Жёсткое правило: НИКОГДА НЕ ТЕРЯТЬ ТЕКСТ

Весь текст из `text` переходит в `gemini_text`. Весь. Без исключений.

Можно:

- Убрать теги разметки (`{g|...}`, `{mf|...}`, `{d|...}`, `{rt_mf|...}`), но **текст внутри тегов остаётся**
- Убрать кавычки `"..."`, но **слова внутри остаются**
- Адаптировать стиль подачи (добавить `[whispers]`, паузы), но **ни одного слова не пропадает**

Нельзя:

- Выбрасывать содержимое `{n}...{/n}` — это не мусор, это нарратив. Текст внутри остаётся в gemini_text (теги `{n}`/`{/n}` выкидываются, текст внутри нет)
- Схлопывать "Прекрасное место для размышлений. Взгляд мужчины устремлен вниз. Отсюда открывается вид..." в "Прекрасное место. Отсюда вид..." — **это потеря текста**
- Писать скрипт, который массово удаляет `{n}` блоки — **каждая фраза обрабатывается индивидуально**

Проверка: сравни `text` и `gemini_text` посимвольно (без учёта тегов и кавычек). Если в gemini_text чего-то не хватает — это баг.

## 2. Правила адаптации `text → gemini_text`

### Что делать с разметкой

- `{n}...{/n}` — Выкинуть теги `{n}` и `{/n}`, **текст внутри остаётся** verbatim. Это нарратив/описание — он озвучивается. Из содержимого `{n}` можно вытащить эмоцию для audio tag, но **текст не выбрасывается**. Пример: `{n}Кунрад смеется{/n}` → `Кунрад смеется` (теги убраны, текст остался)
- `{g|Key}текст{/g}` — Выкинуть теги `{g|...}` и `{/g}`, **текст внутри остаётся**
- `{mf|лев|прав}` — Resolve по `gender`: M → левая часть, F → правая. Пример: `{mf|ым|ой}` → M → `ым`. Если одна сторона пустая (`{mf||иня}`) — M → пусто
- `{name}` — Заменить на "лорд-капитан". Если в той же фразе уже есть "Лорд-капитан" или "Вольный Торговец" — опустить (чтобы избежать дубляжа). Для близких персонажей (Джаэ, Кассия, Йрлиет, Хайнрикс, личные/романтические сцены) возможны "друг мой", "шерин" или опущение — по контексту
- `{d|Key}текст{/d}` — Выкинуть теги `{d|...}` и `{/d}`, **текст внутри остаётся** (ссылка на прошлое решение игрока, для озвучки неважна)
- `{rt_mf|лев|прав}` — Аналог `{mf}`, то же разрешение по `gender`
- `"...диалог..."` — Внешние кавычки убрать (Gemini сам интонирует). Внутренние кавычки (вроде `"Лорд-капитан"`) — оставить
- `—` (тире) — Оставить
- `...` — Оставить или заменить на `[short pause]`
- `\n` (перенос строки) — Склеить в одну строку, но **слова не терять**
- Лишние пробелы — Схлопнуть

> **Почему теги выкидываются, а не оставляются:**
> `{g|...}`, `{d|...}`, `{mf|...}`, `{rt_mf|...}`, `{n}...{/n}` — это разметка **игрового движка** Owlcat (склонения, род, ссылки, нарратив, runtime-подстановки). Gemini TTS эти теги **не понимает** и читает буквально: произнесёт вслух _"открывающая фигурная скобка g вертикальная черта многоточие..."_. Поэтому теги обязательно удаляются, а текст внутри идёт в речь как обычные слова. Акцент/интонация добавляются audio tags только если это диктуется контекстом (personality, нарратив), а не наличием тега.

## 3. Выбор audio tags по контексту

### Из `{n}...{/n}` нарратива

- шепчет, тихо, вполголоса → `[whispers]`
- смеётся, хохочет, усмехается → `[laughs]`, `[chuckles]`, `[amused]`
- кричит, рявкает, гремит → `[shouting]`
- вздыхает, выдыхает → `[sighs]`
- колеблется, медлит, запинается → `[short pause]`, `[nervousness]`
- качает головой → `[sighs]` или пауза
- (тонко) улыбается → `[sly]`, `[amused]`
- серьёзно кивает → `[serious]`
- яростно, гневно, с ненавистью → `[frustration]`, `[anger]`
- испуганно, дрожит, боится → `[trembling]`, `[nervousness]`
- саркастично, с издёвкой → `[sarcastic]`
- устало, без сил → `[tired]`
- удивлённо, изумлённо → `[amazed]`
- задумчиво, размышляет → `[curious]`, пауза

### По `personality` персонажа

- коварный, манипулятивный, вкрадчивый → `[sly]`, `[whispers]`, `[amused]`, паузы
- властная, жёсткая, решительная → `[firm]`, `[serious]`, короткие фразы
- суровый, верный, строгий → `[firm]`, `[serious]`
- уставшая, циничная → `[tired]`, `[sarcastic]`
- холодный, принципиальный → `[serious]`, `[neutral]`
- пламенная, фанатичная → `[determination]`, `[firm]`
- монотонный, логичный → минимум тегов, `[neutral]`
- хитрая, игривая → `[mischievously]`, `[chuckles]`, `[amused]`
- ранимая, застенчивая → `[gently]`, `[warmly]`, паузы
- меланхоличная, спокойная → `[gently]`, `[tired]`
- хищный, садистичный → `[sly]`, `[amused]`, `[slow]`
- грубый, воинственный → `[firm]`, `[shouting]`
- тихая, холодная → `[whispers]`, `[serious]`

### Если нет явного указания

- Один `[short pause]` на каждые 2-3 предложения — для естественности
- Не добавлять теги на каждую фразу — только где есть эмоциональный маркер

## 4. Инструкция для саб-агента

### Вход

Файл `catalog/people/{Character}.yaml`. Из меты:

- `name` — имя персонажа
- `gender` — M/F (нужно для `{mf|...}`)
- `personality` — описание характера (нужно для выбора тегов)
- `gemini_voice` — голос Gemini (для справки)

Из каждой phrase:

- `guid` — идентификатор (не трогать)
- `event` — имя ивента (не трогать)
- `text` — сырой текст с разметкой
- `speaker` — кто говорит (имя персонажа, `null` если не определён)
- `gemini_voice` — голос Gemini для этой фразы. Если `null` — говорящий не определён, используй `[neutral]` без голоса
- `gemini_text` — `null` (надо заполнить)

> **Про `speaker`:** не все фразы в файле принадлежат персонажу из `name`.
> Пример: в `Кунрад_Войгтвир.yaml` ~20% фраз говорят Теодора или Морт.
> Поле `speaker` определяет говорящего по `{n}...{/n}` блокам.

### Выход

Та же phrase, но с заполненным `gemini_text`.

Формат вывода — обновлённый фрагмент YAML, который можно применить
к исходному файлу (патч или in-place).

### Как подходить

Механический find-and-replace убивает голос. Вместо этого:

0. **Определи говорящего**
   - Прочитай `speaker` в phrase
   - Если `speaker` совпадает с `name` из меты → используй `personality` и `gemini_voice` из этого файла
   - Если `speaker` НЕ совпадает с `name` (другой персонаж):
     - Открой `catalog/people/{Speaker}.yaml`, возьми оттуда `personality` и `gemini_voice`
     - Применяй их вместо текущего файла
   - Если `speaker: null`:
     - Смотри на `gemini_voice`. Если `null` — говорящий не совпадает с файловым персонажем. Используй `[neutral]`, не применяй `personality`
     - Посмотри `{n}...{/n}` в тексте. Если там роль или чужое имя ("Архмилитант", "Морт", "Сенешаль", "Мастер шепотов") или описание чужого действия — это НЕ файловый персонаж. Используй `[neutral]`, не применяй `personality`
     - Если описание безличное ("ваш собеседник", "мужчина") — скорее всего говорит файловый персонаж
     - Если сомневаешься — `[neutral]`
   - Если файл спикера не найден → `[neutral]`

1. **Прочитай фразу** — пойми, что персонаж говорит и зачем
2. **Посмотри на event** — имя ивента часто подсказывает контекст:
   - `PRL_KunradIntroduction_01` — первое знакомство, вежливый тон
   - `PRL_KunradReveal_05` — раскрытие заговора, напряжение
   - `Combat_*` — бой, короткие рубленые фразы
   - `RMNC_*` — романтика, тепло
3. **Посмотри на personality персонажа** — из YAML-меты:
   - `"коварный, манипулятивный"` → его речь всегда с подтекстом, даже когда он вежлив
   - `"властная, жёсткая"` → приказы, никаких сомнений
4. **Resolve разметку** — но не тупо, а с пониманием:
   - `{n}Кунрад смеется и качает головой.{/n}` — текст остаётся. Он смеётся → добавить `[chuckles]` перед нарративом
   - `{mf|ым|ой}` — выбрать по `gender` из меты
   - `{g|...}` — теги выкинуть, текст внутри оставить
   - `{name}` — заменить на "лорд-капитан" (или опустить при дубляже)
5. **Audio tags — только по делу.** Не надо вешать тег на каждую фразу.
   Тег нужен когда:
   - В `{n}` описана эмоция, которую без тега не передать
   - Personality диктует особую подачу (шепот, сарказм, твёрдость)
   - Фраза короткая, но эмоционально заряженная
6. **Готовый `gemini_text` — это живая речь.** Представь, что персонаж
   говорит это вслух. Звучит естественно? Если нет — перепиши.

### Примеры разбора (откуда брать контекст)

**Фраза 1:**

```yaml
event: PRL_KunradIntroduction_01
personality: "коварный, манипулятивный, вкрадчивый"
gender: M
text:
  '"Прекрасное место для размышлений". {n}Взгляд приблизившегося к вам мужчины устремлен вниз.{/n}
  "Отсюда открывается лучший вид на кафедральный собор. Завораживает, не правда ли?"'
```

Разбор:

- Event: первое знакомство, Кунрад представляется → тон вежливый, но с подтекстом
- Personality: коварный → он не просто болтает, он прощупывает собеседника
- `{n}`: нарратив сохраняется. Эмоции нет — тег не нужен
- Кавычки убрать, текст склеить
- Итог: `[sly] Прекрасное место для размышлений. Взгляд приблизившегося к вам мужчины устремлен вниз. Отсюда открывается лучший вид на кафедральный собор. Завораживает, не правда ли?`

**Фраза 2:**

```yaml
event: PRL_KunradReveal_12
personality: "коварный, манипулятивный, вкрадчивый"
gender: M
text:
  '{n}Кунрад злобно усмехается.{/n} "Ты думал, я буду играть по твоим правилам?
  {g|...}Империум{/g} — всего лишь инструмент. А инструменты... {n}он делает паузу{/n} ...не выбирают".'
```

Разбор:

- Event: раскрытие, конфликт → тон угрожающий, презрительный
- Personality: коварный, манипулятивный → насмешка, превосходство
- `{n}` первый: злобно усмехается → `[amused]` + нарратив остаётся
- `{n}` второй: делает паузу → `[short pause]` + нарратив остаётся
- Итог: `[amused] Кунрад злобно усмехается. Ты думал, я буду играть по твоим правилам? Империум — всего лишь инструмент. А инструменты... [short pause] он делает паузу ...не выбирают.`

**Фраза 3 (короткая):**

```yaml
event: PRL_KunradChoice_01
text: '"Да. И вскоре вы с ним познакомитесь".'
```

Разбор: короткая, без нарратива, без эмоций. Просто очистить кавычки.
Итог: `Да. И вскоре вы с ним познакомитесь.`

## 5. Примеры

### Кунрад (M, коварный, Sadaltager)

**До:**

```yaml
text:
  '"Прекрасное место для размышлений". {n}Взгляд приблизившегося к вам мужчины устремлен вниз.{/n}
  "Отсюда открывается лучший вид на кафедральный собор. Завораживает, не правда ли? Свидетельство
  величия {g|...}Бога-Императора{/g}, нашедшее безукоризненное воплощение".'
```

**После (весь текст сохранён, только очищены теги):**

```yaml
gemini_text: "[sly] Прекрасное место для размышлений. Взгляд приблизившегося к вам мужчины устремлен вниз. Отсюда открывается лучший вид на кафедральный собор. Завораживает, не правда ли? Свидетельство величия Бога-Императора, нашедшее безукоризненное воплощение."
```

### Теодора (F, властная, Kore)

**До:**

```yaml
text:
  '{n}Теодора бросает на вас гневный взгляд.{/n} "Ты смеешь перечить мне на моем же корабле?
  {g|...}Империум{/g} не прощает предательства, запомни это, {name}!"'
```

**После (нарратив сохранён, теги очищены, {name} → лорд-капитан):**

```yaml
gemini_text: "[firm] Теодора бросает на вас гневный взгляд. Ты смеешь перечить мне на моём же корабле? Империум не прощает предательства, запомни это, лорд-капитан!"
```

### Абеляр (M, суровый, Algenib)

**До:**

```yaml
text:
  '"Лорд-капитан, {n}Абеляр отдаёт честь.{/n} докладываю: обстановка стабильна. Экипаж
  готов к переходу через варп. {n}старый воин выпрямляется.{/n} Ждём только вашего приказа".'
```

**После (нарратив сохранён):**

```yaml
gemini_text: "[serious] Лорд-капитан, Абеляр отдаёт честь. Докладываю: обстановка стабильна. Экипаж готов к переходу через варп. [short pause] Старый воин выпрямляется. Ждём только вашего приказа."
```

## 6. Ограничения Gemini TTS

- **Макс. токенов на вход:** 8,192
- **Макс. токенов на выход:** 16,384 (~несколько минут)
- **Язык тегов:** Английский (даже для русского текста)
- **SSML:** Не поддерживается — только audio tags
- **500 error:** Бывает рандомно — нужен retry
- **Ложный запрет:** Расплывчатый промпт → `PROHIBITED_CONTENT`. Нужен чёткий `#### TRANSCRIPT`

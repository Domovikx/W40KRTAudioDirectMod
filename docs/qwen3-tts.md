## Параметры Генерации

Официальный `generation_config.json` модели (1.7B-CustomVoice):

| Параметр                | Дефолт   | Наш current | Что делает                                                       |
| ----------------------- | -------- | ----------- | ---------------------------------------------------------------- |
| `temperature`           | **0.9**  | 0.7         | Случайность: выше → разнообразнее, но риск артефактов            |
| `top_k`                 | **50**   | —           | Сэмплинг только из top-K токенов: 30-50 оптимально               |
| `top_p`                 | **1.0**  | —           | Nucleus sampling: 0.9 — умеренный отсев хвостов                  |
| `repetition_penalty`    | **1.05** | —           | Штраф повторов: 1.0 = выкл, 1.05-1.1 — лёгкий                    |
| `do_sample`             | true     | true        | Вкл/выкл stochastic sampling (false = greedy)                    |
| `max_new_tokens`        | **8192** | 2048        | **8192** — для длинных фраз. 2048 маловато (>10s текст обрезает) |
| `subtalker_temperature` | **0.9**  | —           | То же, для внутреннего codec predictor                           |
| `subtalker_top_p`       | **1.0**  | —           | То же, для codec predictor                                       |
| `subtalker_top_k`       | **50**   | —           | То же, для codec predictor                                       |
| `subtalker_dosample`    | true     | —           | Вкл/выкл сэмплинг в codec predictor                              |
| `language`              | `"Auto"` | `"Russian"` | `"Russian"` даёт лучший русский                                  |
| `dtype`                 | —        | bfloat16    | bfloat16 (родной), fp32 (медленнее, 4.7ГБ RAM вместо 3.2ГБ)      |

**Важно про max_new_tokens:** дефолт 8192 (а не 2048). Для коротких реплик (5-15 слов) ~1024 токена. 2048 обрезает фразы >~10-12s.

**Важно про температуру:** 0.7 — ровнее и стабильнее, 0.9 — выразительнее, может давать артефакты.

### Что такое fp32 / bfloat16?

| Тип                | Бит | RAM (1.7B) | Скорость        | Когда использовать                    |
| ------------------ | --- | ---------- | --------------- | ------------------------------------- |
| **float32 (fp32)** | 32  | ~4.7 GB    | Медленнее (~2x) | **Максимальное качество. Рекомендую** |
| **bfloat16**       | 16  | ~3.2 GB    | Быстро          | Чуть хуже качество, меньше RAM        |

**Важно:** float32 даёт заметно лучшее качество на слух (глубина, чистота голоса). bfloat16 быстрее и экономит RAM, но проигрывает в качестве. Для финальной озвучки используем **float32**.

### Scene Presets

Параметры генерации по типу сцены — `config/default.yaml` → `qwen3_scene_presets`:

| Пресет | Temperature | top_p | Когда использовать |
|--------|------------|-------|-------------------|
| `narrator` | **0.2** | 0.85 | Закадровый нарратор — макс. стабильность |
| `background_npc` | **0.2** | 0.8 | Массовка / фоновые NPC — консистентность |
| `dialog` | **0.2** | 0.85 | Диалоги NPC / Капитан — естественно |
| `combat` | **0.4** | 0.95 | Боевые реплики / Приказы — энергично (+ instruct `[Тон: напряжённый]`) |
| `warp` | **0.65** | 0.98 | Варп-сущности / Демоны — макс. вариативность + реверб |
| `default` | 0.2 | 0.85 | Универсальный профиль |

Использование в YAML:
```yaml
parts:
  - text_clean: "..."
    voice: Ryan
    scene: dialog       # автоматом temp=0.2, top_p=0.85
    output: "part.wav"
```

Per-part override — если нужно перебить сцену:
```yaml
  - text_clean: "..."
    voice: Ryan
    scene: dialog
    temperature: 0.4    # override поверх scene
    instruct: "Reverent, awestruck"
    output: "part.wav"
```

### Рекомендуемые параметры для лучшего качества

Официальные дефолты из `generation_config.json` — уже оптимальны для большинства случаев. Небольшая корректировка для диалоговой озвучки:

| Параметр                | Дефолт   | **Рекомендую** | Обоснование                                                                            |
| ----------------------- | -------- | -------------- | -------------------------------------------------------------------------------------- |
| `dtype`                 | bfloat16 | **float32**    | **Лучшее качество на слух.** bfloat16 быстрее, но заметно хуже                         |
| `temperature`           | 0.9      | **0.85**       | Баланс выразительности и стабильности (0.9 по дефолту, 0.7 было у нас — слишком ровно) |
| `top_k`                 | 50       | **50**         | Дефолт — проверенный оптимум                                                           |
| `top_p`                 | 1.0      | **0.95**       | Срезает 5% самых маловероятных токенов — меньше артефактов                             |
| `repetition_penalty`    | 1.05     | **1.05**       | Предотвращает зацикливание на повторах                                                 |
| `max_new_tokens`        | 8192     | **8192**       | Чтобы гарантированно не обрезать диалоговые фразы                                      |
| `do_sample`             | true     | true           | Без сэмплинга голос звучит роботизированно                                             |
| `subtalker_temperature` | 0.9      | **0.9**        | Дефолт codec predictor                                                                 |
| `subtalker_top_p`       | 1.0      | **1.0**        | Дефолт                                                                                 |
| `subtalker_top_k`       | 50       | **50**         | Дефолт                                                                                 |

Обоснование: официальный eval Qwen3-TTS (таблицы в HF model card) для всех бенчмарков использовал именно эти дефолты (кроме `max_new_tokens=2048` для коротких тестов). Russian WER 4.734 — лучший результат среди CustomVoice-моделей.

Если хотите **максимум выразительности** (с риском микро-артефактов): `temperature=0.9, top_p=1.0`.
Если хотите **максимум стабильности** (чуть ровнее): `temperature=0.8, top_p=0.9`.

## Full ICL Pipeline (Voice Clone)

Генерация всех реплик персонажа единым голосом через Base модель.

### Flow

```
1. VoiceDesign                   → generate_voice_design(instruct) → reference.wav + .txt
2. Base + create_voice_clone_prompt(ref_audio, ref_text)          → VoiceClonePromptItem
3. Base + generate_voice_clone(text, voice_clone_prompt)          → output.wav
```

### Шаг 1: Создать референс

```bash
python tools/qwen3_voice_design.py voice_name [instruct.txt] [text.txt]
```

Создаёт `refs/{voice_name}_reference.wav` + `.txt`.

### Шаг 2: Батчевая генерация

```bash
python tools/qwen3_full_icl.py
```

Читает `config/voices.yaml` и `catalog/people/*.yaml` с multi-part фразами, генерирует `output/full_icl/{voice_name}/{guid}__{N}.wav` (по файлу на часть).

### Шаг 3: Склейка частей

```bash
python .opencode/skills/qwen3-full-icl/concat_parts.py output/full_icl/kunrad/
```

Собирает `guid__1.wav + guid__2.wav + ... → guid.wav` с паузой 300ms между частями.

### Конфигурация

`config/voices.yaml`:
```yaml
references:
  voice_name:
    wav: refs/voice_name_reference.wav
    txt: refs/voice_name_reference.txt
```

Параметры — `config/default.yaml` → секция `qwen3_base_*`.

### Технические детали

- **x_vector_only_mode=false** — Full ICL (тембр + стиль речи из референса)
- **temperature=0.2** — стабильность голоса между фразами
- Модель не требует ударений/SSML — чистый русский текст
- Референс 30-60с оптимален

## Как добавить голос для персонажа

1. Выбрать голос (Dylan/Ryan/Aiden для мужчин, Vivian/Serena/Sohee для женщин)
2. Выбрать инструкцию под характер персонажа
3. Сгенерировать:
   ```python
   model.generate_custom_voice(
       text="...", language="Russian",
       speaker="Ryan", instruct="Уверенный, командный голос"
   )
   ```
4. Послушать, при необходимости изменить инструкцию

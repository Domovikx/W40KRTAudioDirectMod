# CosyVoice 3.0 — локальный TTS-пайплайн (voice clone)

Модель: `FunAudioLLM/Fun-CosyVoice3-0.5B-2512` (Alibaba, Apache 2.0, релиз 12.2025).
Zero-shot voice cloning, 9 языков (включая русский), cross-lingual (англ. референс → рус. текст).
Наш кейс: референсы — оригинальные англ. голоса актёров из игры (`refs/samples_en/`), текст — русский.

## Установка (готово 2026-08-28)

- Repo + venv + модель: `C:\tools\cosyvoice3\` (~10 ГБ)
  - `CosyVoice\` — исходники (main, 2026-08)
  - `.venv\` — Python 3.10 (torch 2.3.1 CPU, transformers 4.51.3, onnxruntime 1.18)
  - `pretrained_models\Fun-CosyVoice3-0.5B\` — веса
- Запуск: `C:\tools\cosyvoice3\.venv\Scripts\python.exe tools/cosyvoice3_demo.py`

## Скрипт

`tools/cosyvoice3_demo.py` — single-part / multi-part (speaker→ref, склейка с `--gap`),
все флаги: `--guid --char --text --ref --speed --instruct --sampling --rl --base --single --out`.

## Рычаги качества (по субъективному рейтингу 2026-08-28)

| Рычаг | Описание | Итог |
|-------|----------|------|
| **RL-веса** | `llm.rl.pt` — пост-тренировка reward-model. Default в скрипте | **Лучший single-голос** |
| **Multi-part + реф на голос** | части фразы = отдельный прогон со своим рефом (speech + narrator) | **Лучший общий результат** |
| instruct2 | `--instruct angry/sad/happy/loud/soft/fast/slow` — эмоции/темп | angry — не зашло |
| sampling | `--sampling top_p,top_k,tau_r` — правка RAS-семплера в yaml | 0.9/50 — не зашло |
| speed | `--speed 0.5–2.0` — пост-интерполяция mel | не пробовали |
| Референс | 3–10с чистой речи; тишина/музыка в рефе портят тембр | главный ручной рычаг |

### RL vs Base

В `pretrained_models\Fun-CosyVoice3-0.5B\` лежат оба LLM: `llm.pt` (base) и `llm.rl.pt`.
Скрипт делает hardlink-копию модель-дира (`Fun-CosyVoice3-0.5B_rl`) и меняет
`llm.pt ← llm.rl.pt` (base сохраняется как `llm.base.pt`). `--base` — обратный выбор.

### Язык

- Явного `language=` параметра НЕТ (в отличие от Qwen3-TTS). Один мультиязычный LLM,
  язык выводится из текста; русский — один из 9 языков обучения.
- Токенизатор имеет спец-токены языков (`<|en|>`, `<|ru|>`, `allowed_special='all'`) —
  можно подставлять в текст вручную (в CV2 это было штатно, в CV3-примерах не используется).
- Instruction-промпт (`infer2`/префикс) — свободный текст, список в
  `cosyvoice/utils/common.py` — только подсказки. Можно пробовать «Please say it in Russian».

### Референсы CV3

`refs/samples_en_cosy/` — 10с, 24kHz mono, нарезаны из `refs/samples_en/` (ffmpeg -ss 2.5 -t 10).
Референсы под каждого спикера добавлять туда: `{Speaker}.wav` (пробел → `_`), нарратор — `Narrator.wav`.

## Технические заметки

- Префикс `You are a helpful assistant.<|endofprompt|>` — обязателен для CV3 (из-за него
  text_normalize сам отключается; для русского дополнительно передаём `text_frontend=False`)
- wetext на этой машине падает (403 с modelscope) → frontend выключен, для русского не критично
- CPU: загрузка модели ~10с, генерация RTF ~7–15 (одна реплика 0.5–2 мин).
  Для батча — грузить модель один раз на процесс, не на фразу
- `speech_tokenizer_v3.onnx` лимит: промпт ≤ 30с (в коде)
- ttsfrd — только Linux; не нужен
- Демки: `refs/samples_en_demo_cosy/` (победители: RL-сингл + multi-voice),
  Q3-демки — `refs/samples_en_demo_q3/`

Задача: озвучить фразу `bd180c6f` (Джаэ) через CV3. На слух — шипение.

### Находки

1. **Реф был склеен из двух тейков** (whisper word-timestamps всего 15с файла:
   фраза записана дважды; кат 2.5–12.5с рвал слово `well,` посередине).
   Перерезан на чистый одинарный тейк 7.2с (7.66–14.86с исходника).
   Добавлен `refs/samples_en_cosy/Jae_Heydari.txt` (whisper-large-v3-turbo,
   полный транскрипт тейка) — нужен для zero_shot.
2. **Нестандартный сэмплинг 0.9/50 протёк во все копии модели.** Официальный
   дефолт CV3 — `top_p: 0.8, top_k: 25`; после A/B «0.9/50 — не зашло» значения
   остались, а `hardlink_tree` в `cosyvoice3_demo.py` (os.link) связал все
   модель-диры одним inode — правка yaml меняла все копии. Вернули сток 0.8/25;
   в скрипте hardlink → `shutil.copy2` (`copy_tree`).
3. **Шипа в паузах нет.** Измерение «hiss-in-pauses» (8кГц+ RMS в тихих окнах,
   скрипт в сессии): все варианты −84…−94 дБ, реф −88 дБ. «Шипение» = яркость
   тембра ВО ВРЕМЯ речи: CV3-выход на ~4 дБ ярче рефа в полосе 10–12 кГц

### Вздох в конце реплики

Наблюдение: в конце части (фраза `fdbb7e9d`) модель дорисовывала неуместный
вздох — CV3 умеет генерировать дыхание (`[breath]` — официальный текстовый
токен, см. `example.py`), и breath-токены могут появляться перед EOS сами.

Диагностика (RMS хвостов, 0.6с): у длинной фразы `9157f37f` хвосты оказались
чистыми (−22…−24 дБ — это последнее слово, не вздох). Вывод: вздох — артефакт
конкретной фразы/сида, не системный.

Фикс в `cosyvoice3_demo.py`: флаг `--tail-trim` (обрезка тихого хвоста
< −45 дБ + fade-out 40 мс на КАЖДОЙ части перед склейкой) + `--fade-ms`.

### Документация и конфиги CV3 (что читать)

- **Репозиторий**: https://github.com/FunAudioLLM/CosyVoice (`example.py` —

- **Исходник офиц. HF Space**: https://huggingface.co/spaces/FunAudioLLM/Fun-CosyVoice3-0.5B/blob/main/app.py —
  единственный эталонный конфиг инференса: **base-модель (не RL)**, режимы
  zero_shot/instruct2, seed+speed+stream, prompt ≤ 10с, текст ≤ 200 симв.,
  постпроцесс ТОЛЬКО рефа (librosa trim + peak 0.8 + 0.2с хвост)
- **vllm-omni конфиг** (полная карта параметров): https://docs.vllm.ai/projects/vllm-omni/en/latest/api/vllm_omni/transformers_utils/configs/cosyvoice3/
- Локально: `C:\tools\cosyvoice3\CosyVoice\` (`README.md`, `FAQ.md`, `webui.py`)

**Температуры у CV3 нет.** Все ручки инференса:

| Где | Параметр | Дефолт |
|---|---|---|
| API | `stream`, `speed`, `text_frontend`; `seed` через `set_all_random_seed` | False/1.0/True/random |
| yaml → RAS-сэмплинг | `top_p`, `top_k`, `win_size`, `tau_r` | 0.8 / 25 / 10 / 0.1 |
| yaml → flow CFM | `inference_cfg_rate`, solver, t_scheduler | 0.7 / euler / cosine |
| yaml → HiFT | `nsf_alpha`, `nsf_sigma`, `nsf_voiced_threshold` | 0.1 / 0.003 / 10 |
| код (не yaml) | `min/max_token_text_ratio` (лимит длины генерации) | 2 / 20 |

Известные из issues артефакты и фиксы: клик в начале → fade (PR #379);
шум/музыка в cross_lingual → языковой токен `<|ru|>` в начале текста (#863);
дыхание в тексте управляется `[breath]` (#1016); хвостовые артефакты →
обрезка тишины + fade (#631).

- Soniqo (MLX): `[S1]...[S2]...` + `--speakers s1=a.wav,s2=b.wav` — оркестрация
  (режет по репликам, генерит каждую со своим рефом, склеивает) — как у нас
- CosyVoiceDesktop / CosyVoice3Pro (Speaker Registry) — то же + UI/кэш

  спикерами: единственная «настоящая» мультиозвучка, но 1–2ч данных на спикера
  и без русского → для нас непрактично (25 голосов, русский)

**Потенциальный кастомный ход:** в CV2/3 контент и тембр развязаны (LLM генерит
семантик-токены «что сказать», flow красит голосом через spk-эмбеддинг). Можно:
один LLM-проход на всю фразу (все реплики вместе → связная просодия и контекст),
затем рендер сегментов в flow с разными spk-эмбеддингами. Сложно (разрезка
токен-потока по границам реплик), из коробки нет. Идея на полку — пригодится
для связности multi-part фраз (речь+нарратор).

## ВЕРДИКТ (2026-08-28): Q3-TTS остаётся основным пайплайном

Итог A/B-сравнения: **Q3-TTS (VoiceClone x_vector) победил** — русская фонетика
чище, у CV3 слышен остаточный «китайский» акцент.

Причины акцента CV3:

  игровых актёров сама говорит в EN с акцентом (гипотеза, не подтверждена)

Что пробовали и не помогло: RL-веса (лучшее из CV3, но акцент остался),
zero_shot с whisper-транскриптом, `<|ru|>` токен, instruct2 «speak in Russian»,
sampling top_p/top_k, постпроцессинг рефов (trim+normalize как в офиц. HF Space).

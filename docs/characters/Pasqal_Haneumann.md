# Pasqal Haneumann

## Описание персонажа

- **Пол:** Мужской
- **Возраст:** Неопределённый (вселение в металл)
- **Роль:** Магос Адептус Механикус, технопровидец
- **Характер:** Логичный, отстранённый, монотонный, преданный Омниссии
- **Биография:** Паскаль Ханеуманн — магос Адептус Механикус, служитель Культа Машины. Большая часть его плоти заменена аугментикой, а разум работает по принципу логических цепей и бинарных молитв. Он говорит сухо, по делу, без лишних эмоций — или с эмоциями, которые сам считает «непродуктивными сигналами». Его голос должен звучать механически, ровно, с лёгкими искажениями и металлическими нотками.

## Английский актёр

**Chris Sharpes** — британский актёр, придал Паскалю характерный монотонный «техножреческий» тон.

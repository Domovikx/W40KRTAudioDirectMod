# Kibellah (Kibellah)

## Описание персонажа
- **Пол:** Женский
- **Раса:** Человек
- **Роль:** Убийца из Культа Смерти (Death Cult Assassin), «Вторая Пряха Кровавой Паутины»
- **Характер:** Загадочная, опасная, фанатичная, преданная, молчаливая. Голос — тихий, шепчущий, с оттенком одержимости.
- **Описание:** Член Культа Смерти «Кровавая Паутина», служащая дому фон Валанциус. Ассасин, посвятившая свою жизнь ритуальным убийствам во славу Императора. Появляется в DLC «Void Shadows». Её речь — смесь религиозного фанатизма и ледяного спокойствия профессионального убийцы.

## Английская озвучка
**Abi Horton** — британская актриса озвучивания. Ранее озвучила Dark Eldar Female 2 в базовой игре. Её голос для Кибеллы — низкий, шипящий шёпот, опасный и завораживающий одновременно.

# Marazhai Aezyrraesh (Marazhai Aezyrraesh)

## Описание персонажа
- **Пол:** Мужской
- **Раса:** Друкарий (Тёмный эльдар)
- **Роль:** Спутник (опциональный), владыка Комморры
- **Характер:** Жестокий, хитрый, садистичный, аристократичный, харизматичный, двуличный. Голос — вкрадчивый, с мурлыкающими нотками, но способный взрываться ледяной яростью.
- **Описание:** Друкарий-аристократ из Комморры, владыка своего дома. Жесток и расчётлив, использует людей как пешки. Может стать спутником по еретическому пути. Его речь полна издёвок и скрытых угроз.

## Английская озвучка
**Will De Renzy-Martin** — британский актёр. Его голос передаёт опасную обаятельность друкария — низкий, с хрипотцой, с налётом аристократического презрения.

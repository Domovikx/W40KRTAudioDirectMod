# Generic Male NPC

**Пол:** Мужской
**Роль:** Универсальный NPC для эпизодических персонажей, массовки, случайных прохожих
**Характер:** Нейтральный, адаптивный под контекст сцены
**Описание:** Голос по умолчанию для всех NPC, которые не имеют собственного файла персонажа. Слуги, офицеры, торговцы, горожане, пилоты — любые эпизодические роли. Голос должен быть мужским, нейтральным, спокойным, без ярко выраженных акцентов, чтобы не мозолить уши и подходить под любой контекст. В идеале — «дикторский» русский литературный язык без региональных особенностей.

---

## Кандидаты для русской озвучки

### 1. Дикторское чтение — синтез (Silero «aidar» / Qwen3 «Ryan»)
**Обоснование:** Для массовки и случайных реплик оптимально использовать TTS-синтез с базовым «aidar» (Silero) — нейтральным мужским голосом с хорошей дикцией. Он максимально приближен к дикторскому стандарту, не перетягивает внимание на себя и подходит для любых ситуаций.

### 2. Голос «золотой коллекции»: Вадим Медведев (диктор)
**Обоснование:** Если хочется «живого» голоса — классический диктор Центрального телевидения (в прошлом). Спокойный, уверенный, «незаметный» голос, который идеально подходит для озвучивания интерфейса, описаний и коротких реплик NPC.

### 3. Пётр Иващенко
**Обоснование:** Нейтральный приятный тембр без резких окрасок. Актёр с огромным опытом озвучки эпизодических ролей и «голоса за кадром». Способен звучать дружелюбно, официально или строго — в зависимости от сцены.

### 4. Алексей Мясников
**Обоснование:** Голос, знакомый по сотням RPG — именно он часто звучит у торговцев, стражников и случайных NPC. Немного низковатый, «коренной», но не перетягивающий одеяло на себя. Отличный выбор для «универсального солдата».

### 5. Чередование нескольких голосов
**Обоснование:** Для лучшего погружения имеет смысл заготовить 2-3 нейтральных мужских голоса (Silero: aidar + eugene) и чередовать их в диалогах, чтобы NPC не звучали все одинаково. Это даст иллюзию разнообразия без необходимости подбирать отдельного актёра на каждую эпизодическую роль.
